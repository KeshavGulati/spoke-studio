# Spoke Studio

This repository contains a tool I made to label spoke masks effectively. The tool is live at [https://spoke-studio.keshavgulati785.workers.dev/](https://spoke-studio.keshavgulati785.workers.dev/).

## How To Use
Navigate to the URL, and make an account with an email and a password. This is not for security purposes, and so a password is not required. The identity login helps determine who labelled what mask, and can later be used to assign images to people for labelling.
<br>

### Import Images
Use the *import images* button to import a folder of images to label, and then use the tools available for marking.
